# providers

One file per provider: `<id>.yaml`, where `<id>` is the provider id Connectors uses (for example
`jira`, `slack`, `zendesk`).

The file format is `connectors-definition/1`. Its schema is defined in Connectors and is not
published yet. The design `architecture-design:provider-definitions-and-runtimes` (§ 4, in the Connectors
planning store) shows an illustrative file.
